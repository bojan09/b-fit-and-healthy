# Nutrition and planning database setup

Phase 5 adds the additive migration:

`supabase/migrations/202607190004_nutrition_planning.sql`

Apply it to the same Supabase project after the foundation, onboarding, and core-tracking migrations. It creates the food catalogue, private meal records, curated recipes, saved recipes, weekly planning records, grocery items, indexes, constraints, and row-level-security policies.

The application intentionally handles a missing Phase 5 migration as an empty/unavailable state during local UI review. Logging and planning become persistent after the migration is applied.

## USDA FoodData Central

Set `USDA_FDC_API_KEY` in the local or Vercel server environment to enable external food search. The key is only read by the server adapter and must never use a `NEXT_PUBLIC_` prefix. Without it, the built-in food catalogue and custom foods remain available.

The adapter uses the official Food Search endpoint and identifies USDA FoodData Central in returned attribution. API reference: <https://fdc.nal.usda.gov/api-guide/>

No `.env.example` file is required or generated by this phase.
